# Real purchase lifecycle evidence

`tests/priva-purchase-lifecycle.test.mjs` is the Phase 4 emulator gate. It
uses the current Acton launchpad build, the checked-in settlement-minter fork,
the pinned official wallet artifact, and a real Groth16 proof generated by
`vendor/zk-tele-auth`.

Run it from the repository root:

```bash
npm run test:real-lifecycle
```

The harness covers:

- proof generation, off-chain self-verification, and proof-cell serialization;
- minter admin nomination and claim by the launchpad;
- a real mint into the official jetton wallet, supply/balance checks, and the
  authenticated `excesses#d53276db` settlement acknowledgement;
- excess refund claim ordering, duplicate-claim rejection, and sender-bound
  refund authorization;
- action/query accounting and finalized sale invariants;
- a direct mint rejection/bounce with a refundable pending purchase;
- a downstream wallet failure with the minter's authenticated
  `PRIVA_MINT_FAILURE` callback and supply rollback;
- recipient binding and forged terminal-failure callback rejection.

The final lines are intentionally a gate, not a green release signal. This is
emulator evidence for the fork, not an independent contract review or live
testnet deployment. The public testnet gate remains closed until the exact
fork source and code hash are independently reviewed, the locked-admin
initialization is reproduced on testnet, and the signed deployment manifest
records those hashes and approvals.

The proof artifacts are the checked-in development ceremony artifacts. They
are suitable for explicitly labelled testnet emulator evidence only;
`npm run check:priva-production` must remain fail-closed.
